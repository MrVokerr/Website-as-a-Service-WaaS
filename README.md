## 🛠 Tech Stack & Features

*   **Framework:** React (Vite)
*   **Styling:** Tailwind CSS / CSS Modules
*   **Deployment:** Netlify (CI/CD)
*   **Forms:** Netlify Forms (Serverless)
*   **Performance:** Mobile-First, SEO optimized, Lighthouse optimized

## 🚀 Key Features

*   **Responsive Design:** Flawless rendering across mobile, tablet, and desktop devices.
*   **Lead Generation:** Integrated contact forms with email notifications.
*   **Conversion Focused:** Click-to-call buttons and clear Call-to-Actions (CTAs).
*   **Easy Customization:** Structured codebases allowing rapid adaptation for new clients.
