# Paws N Style - WaaS Template

Live site: https://paws-n-style.netlify.app/

This is a responsive single-page React template built for pet grooming and pet service businesses. It's set up for deployment on Netlify and includes a contact form wired for Netlify form handling.

Quick start

```powershell
npm install
npm run dev
```

Build for production:

```powershell
npm run build
```

Customization: update `src/App.jsx` and the `businessDetails` object to adapt the site for a specific client (brand colors, hero images, contact details, services, etc.).
